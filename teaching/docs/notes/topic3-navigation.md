# Topic 3 navigation and opening

User direction, 3 November 2026: follow Topic 2's manually written contents
style, remove Topic 3's former second page (the four-hour timetable), and use
fewer sections/subsections in long decks.

Both Topic 3 versions now open with title, QT task and an itemized contents
slide. Three numbered sections cover system design, plugin implementation and
evolution, and the integrated lab. There are no subsections or repeated roadmap
pages. Following the user's next instruction, the seven former reference slides
are integrated beside the corresponding concepts, demonstrations and extensions;
there is no appendix. Five hook slides cover lifecycle events, authority/failure
behavior, native plugin registration and a runnable metadata-logging exercise.
The four-hour schedule remains in the instructor guide. Both decks have 86 pages.

This explicit preference supersedes the older automatic `tableofcontents`
roadmap convention for these decks. Do not add automatic roadmaps merely to
satisfy the legacy slide validator's Roadmap-name check. The manual contents
must match the three actual sections in both languages.
