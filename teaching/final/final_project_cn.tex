{\small 金融人工智能编程\hfill 2026 年秋季}\par
{\large\bfseries 期末项目：建立自己的 AI 原生公司}\par
\vspace{4pt}

本项目由个人独立完成。请搭建一家由智能体团队提供金融产品或服务的 AI 原生公司原型，使其能够实际运行。你担任创始人与产品负责人，对金融判断与产品设计负责。围绕明确的用户需求组织智能体团队，通过长程工作流让业务能够重复运行并持续改进。

\projectsection{1. 明确公司、用户与产品}
从你的工作或学习中选择一项金融需求。为公司命名，说明服务谁、解决什么问题，以及产品的价值。例如公司研究服务、量化研究服务或组合监测服务。也接受非金融公司的选题。明确用户收到什么、如何使用，以及如何评价产品质量。设定具有挑战性的业务范围，明确允许使用的数据来源、信息截止时点与运行成本。可参考 \href{https://rogo.com/}{Rogo.com}、\href{https://funda.ai/}{Funda.ai} 和 \href{https://www.harvey.ai/}{Harvey.ai} 等公司的思路。

\projectsection{2. 组建智能体团队}
提供带注释的团队架构与工作流图，以及简短的设计说明。设计协调不同智能体团队的工作流。明确各岗位的输入、输出、工具、技能、知识来源与权限。说明工作分工，以及从接收用户需求到产品验收的依赖关系与交接方式。区分智能体的决策与 Harness/控制器的执行规则，并说明用于计算的确定性代码。写明你作为公司负责人保留哪些决策权与批准权。

\projectsection{3. 提交公司原型及完整 Git 历史}
提交公司与产品说明、团队架构与工作流图、提示词、技能、配置、实现文件、可分享的输入与产品输出，以及核验、更新和恢复的证据。在根目录的 \texttt{README.md} 中写明个人信息、目标用户与产品、环境配置与运行说明、依赖项、文件说明及代码仓库链接（如适用）。开发过程中应持续进行有意义的提交，说明决策、修复与检查。

将\textbf{现有的本地项目文件夹}打包为一个 ZIP 文件，包含全部交付物及\textbf{完整的隐藏目录 \texttt{.git/}}。打包前提交最终修改，保留完整开发历史，不得使用浅拷贝。

压缩包命名为 \texttt{studentID-final-project.zip}。

代码托管平台的“Download ZIP”选项与 \texttt{git archive} 均省略 Git 历史，不符合要求。文件与历史须能在无需访问远程仓库的情况下审阅，且均不得包含凭据、客户隐私数据及其他敏感信息。
