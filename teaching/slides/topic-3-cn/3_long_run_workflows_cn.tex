\begin{frame}{审计重放与确定性}
\begin{itemize}
\setlength{\itemsep}{0.8em}

\item 结果可重复不代表正确；重放时不得再次支付或下单。
\end{itemize}

\begin{frame}{问题台账：未再提及仍未解决}
\begin{itemize}
\setlength{\itemsep}{0.8em}
\item 第 1 轮记录问题 \texttt{pit-001}，并链接到对应证据。
\item 第 2 轮没有提到 \texttt{pit-001}，它仍然是未解决问题。
\item Critic 核验修复后的产物，记录理由后才能关闭问题。
\item 把所有未解决问题带入下一轮任务。
\end{itemize}
\begin{center}\illustrative\end{center}

% Page 21
\begin{frame}{停止条件：通过、修订与终止}
\begin{itemize}
\setlength{\itemsep}{0.8em}
\item 通过：检查通过、问题已解决，同一候选连续两轮完整审查无问题（QT 规则）。
\item 修订：有可检验的修复方案，且仍有轮次和时间预算。
\item 否决或阻断：致命缺陷终止案例；无效提交先退回修复，达到次数上限后阻断。
\item 预算耗尽、进展停滞或用户叫停时，停止并记录原因。
\end{itemize}
\end{frame}

% Page 25
\begin{frame}{持久状态：保存核验后的进度}
\begin{itemize}
\setlength{\itemsep}{0.8em}
\item 记录案例、请求、候选策略和提示词版本 ID，以识别过期回复。
\item 每次状态转换时，保存待处理角色、轮次、重试次数和截止时间。
\item 保存文件路径与哈希，检查内容是否被改动。
\item 保留未解决问题与已核验的修复记录，供恢复运行时读取。
\end{itemize}
\end{frame}

% Page 26
\begin{frame}{故障恢复：先核对，再重试}
\begin{itemize}
\setlength{\itemsep}{0.8em}
\item 超时后先确认任务是否完成，再决定是否有限重试。
\item 报告格式错误或缺少必选报告时，返回具体错误并要求修复。
\item 封存文件被改动时，阻止推进（\texttt{BLOCKED}），保留原有记录并检查原因。
\item 外部操作结果不明时，先对账，再决定是否重试，避免重复下单或支付。
\end{itemize}
\end{frame}

\begin{frame}{运行轨迹：还原每一步}
\begin{center}
\resizebox{.94\textwidth}{!}{\input{figures/decision_trace}}

\item 把数据快照、计算结果、审查问题和版本审批关联起来，供后续核查。
\item 轨迹记录实际操作与证据文件；它不是模型内部的隐藏推理。
\end{itemize}
\end{frame}

\begin{itemize}
\item 检查 \texttt{request\_id}、专家报告、数值输出与控制器的下一步安排。
\item 脚本排练标为 \texttt{SCRIPTED\_REHEARSAL}；真实团队运行需要宿主调用记录佐证。
\end{itemize}
\end{frame}

% Page 41
\begin{frame}{四道检查：何时可以继续}
\begin{itemize}
\setlength{\itemsep}{0.8em}
\item Generator 的三份专家报告齐备，且请求 ID 与轮次匹配。
\item 候选策略代码已运行，并通过确定性数值检查。
\item Critic 在新的上下文中完成三份审查报告，并处理前轮遗留问题。
\item 核验后的证据满足验收规则，或触发明确的停止条件。
\end{itemize}
\end{frame}

% Page 42
\begin{frame}{故障修复：处理无效提交\handsup}
\begin{itemize}
\setlength{\itemsep}{0.8em}
\item 缺少必选报告时，案例停留在当前角色，等待补齐。
\item 请求 ID 过期或不匹配时，拒绝提交，不进入下一步。
\item 报告齐备并匹配后，再检查文件哈希与其他推进条件。
\item 请在临时案例中修复一次提交并核对下一步；不要改动已封存证据。
\end{itemize}
\end{frame}

% Page 43
\begin{frame}{证据重放：核对三类结果}
\begin{itemize}
\setlength{\itemsep}{0.8em}
\item 查看 \texttt{state.json}、路由轨迹和保存的角色产物，还原过程。
\item 固定输入与配置，重新计算并比较数值结果。
\item 比较模型行为时，分别保留每次调用的运行记录。
\item 新评测需要新案例；重新打开已有案例会继续或复用原状态。
\end{itemize}
\end{frame}

% Page 44
\begin{frame}{中断恢复：接着未完成的步骤}
\begin{center}
\resizebox{.94\textwidth}{!}{\input{figures/resume_case}}
\end{center}
\smallskip
\begin{itemize}
\item 已结束的案例直接返回保存的结论，不会重复执行。
\item 代码、数据快照或角色要求变化后，需要新建案例。
\end{itemize}
\end{frame}
